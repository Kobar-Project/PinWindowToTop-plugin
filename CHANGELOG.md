# Changelog

## 1.1.0 - 2026-11-02

- Canlı look: tooltip and button use the Canlı surface, stroke, radius and shadow tokens (with fallbacks for older hosts); Material Symbols Rounded with Outlined fallback. The plugin is a bar widget and has no panel.
- Bar tile: label only (host label template); manifest `bar` block added (`sensitive: false`, `defaultSize: icon`).
- Redesigned from its functions: a panel with "Pick a window", "Stop waiting", "Unpin" and "Unpin all" (was a double-click), the frame colour and width as a card; a dot on the bar item while a window is pinned. The inline widget stays for older hosts.

## 1.0.3

- Bar icon: no round fill behind the icon, same colour and weight as other bar icons.
